# Sistema de Login

login/ – Módulo responsável pela autenticação e gestão de usuários.
Inclui:

- domain – Entidades e repositórios de domínio (User, Token, UserRepository).

- configuration – Configurações de segurança e autenticação.

- controller – Endpoints de login, cadastro e consulta de usuários.

- repository – Implementações de acesso a dados e comunicação com outras camadas.

- security – Filtros, validação de JWT, geração de tokens e regras de segurança.
